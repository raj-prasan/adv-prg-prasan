 # Todo Manager
 
 ## Overview
 
 Todo Manager is a simple application for creating, organizing, and tracking tasks.
 
 ## Features
 
 - Add new tasks
 - Edit task details
 - Mark tasks as complete
 - Delete tasks
 - View pending and completed items
 
 ## How to Use
 
 1. Open the application.
 2. Create a task with a clear title.
 3. Update the status when work is in progress or done.
 4. Remove tasks that are no longer needed.
 
 ## Example
 
 ```text
 Add: Finish assignment
 Complete: Finish assignment
 ```
 
 ## Notes
 
 - Keep task titles short and descriptive.
 - Review your list regularly to stay organized.
