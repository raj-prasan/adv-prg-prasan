# Student Management System

## Description
This assignment is a **Student Management System** that helps manage student information in an organized way. It can be used to store, view, update, search, and delete student records.

## Objectives
- Maintain student records efficiently
- Support basic CRUD operations
- Provide a simple interface for user interaction
- Organize data for easy access and management

## Features
- Add new student details
- Display all stored students
- Search for a student by ID or name
- Update existing student information
- Delete student records
