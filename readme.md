# Activity Log Analyzer

## Overview
Activity Log Analyzer is a simple program for reviewing, filtering, and summarizing activity log data. It helps identify usage patterns, important events, and basic statistics from log entries.

## Features
- Load activity log data from a file
- Display log entries in a readable format
- Filter logs by date, user, or event type
- Count and summarize activity records
- Help identify trends or unusual activity

## How to Use
1. Place the activity log file in the project folder.
2. Run the program.
3. Choose the analysis option you want.
4. Review the output shown in the console or report.

## Example Output
```text
Total records: 120
Most active user: user01
Most common event: login
```

## Requirements
- A compatible Python environment or the runtime used by the project
- An input activity log file in the expected format
